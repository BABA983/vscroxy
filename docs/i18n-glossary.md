# Interface glossary (English → Simplified Chinese)

The terms the interface uses, so screens, menus and notices stay consistent.
English is the source language: a message is written in English first and
translated from it. Product and protocol names (vscroxy, Postman, Charles,
Proxyman, HTTP, HTTPS, TLS, WebSocket, Socket.IO, SSE, MCP, MQTT, gRPC,
GraphQL, OpenAPI, Protobuf, JSON, HAR, cURL, App) keep their spelling.
